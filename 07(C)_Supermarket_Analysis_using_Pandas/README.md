**Problem Statement**

> A supermarket chain wants category-wise sales analysis. Perform grouping, aggregation, and pivot table analysis using Pandas.

For this problem, we will learn three important Pandas concepts:

1. Grouping (groupby())
2. Aggregation (sum(), mean(), count(), min(), max())
3. Pivot Tables (pivot_table())

The given dataset contains 30 sales transactions across different stores, categories, products, dates, quantities, and prices.
